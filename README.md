# Campus Life Organizer

大学生活を効率的に管理するためのオールインワン・ダッシュボードです。

**URL:** [https://a226t002-alt.github.io/my-app-2026/](https://a226t002-alt.github.io/my-app-2026/)

## 主な機能と使い方

### 1. 時間割 (Timetable)
今学期の授業スケジュールを管理できます。
- **登録・編集:** 空白のセルまたは既存の授業をクリックすると、入力モーダルが開きます。
- **情報の管理:** 授業名、教室、担当教員を入力して保存できます。
- **削除:** 編集モーダルで「削除」を選択するか、授業名を空にして保存します。

### 2. 課題・Todo (Task Management)
提出物や個人的なタスクを期限とともに管理できます。
- **追加:** タスク名と期限（任意）を入力して「追加する」ボタンを押します。
- **完了:** チェックボックスをクリックすると、完了状態（打ち消し線）になります。
- **削除:** ゴミ箱アイコンをクリックしてタスクを削除します。

### 3. メモ (Memos)
ちょっとした備忘録や、Wi-Fiパスワードなどの情報を保存できます。
- **作成:** 左側のテキストエリアに内容を入力し「保存する」を押すと、右側にカード形式で追加されます。
- **閲覧:** タイムスタンプとともに一覧表示されます。
- **削除:** カードの右上にあるゴミ箱アイコンで削除できます。

### 4. リンク (Quick Links)
大学のポータルサイトや図書館など、よく使う外部サイトへのリンクをまとめられます。
- **登録:** タイトルとURLを入力して追加します（`http://` 等は自動補完されます）。
- **アクセス:** 登録されたリンクをクリックすると、新しいタブでサイトが開きます。

## 開発・実行方法

このプロジェクトは React と Tailwind CSS を使用して構築されています。

1. リポジトリをクローン
2. 依存関係のインストール: `npm install`
3. 開発サーバーの起動: `npm start`
